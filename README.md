# มดนักสำรวจ — เกมกระดานเล่นร่วมกันแบบเรียลไทม์

เวอร์ชันนี้ต่อยอดจากไฟล์เกมเดิม (index.html, waiting-room.html, board.html,
spectator.html) โดยเพิ่มเซิร์ฟเวอร์ Node.js + Socket.IO เข้ามาแทนที่ระบบ
`BroadcastChannel` เดิม (ซึ่งซิงค์ข้อมูลได้แค่ในเบราว์เซอร์/อุปกรณ์เดียวกัน)
ทำให้ตอนนี้แต่ละกลุ่มสามารถเปิดเกมจากคนละคอมพิวเตอร์/มือถือ สร้างห้องด้วยรหัส
PIN แล้วเล่นพร้อมกันแบบเรียลไทม์ผ่านอินเทอร์เน็ตได้จริง

**หน้าตา ปุ่ม และโค้ดเกมเดิมทั้งหมดยังเหมือนเดิมทุกอย่าง** — ส่วนที่แก้ไขคือ
เพิ่มชั้นการเชื่อมต่อเครือข่าย (network layer) เข้าไป ไม่ได้เขียนเกมใหม่

## โครงสร้างไฟล์

```
├── server.js         เซิร์ฟเวอร์ Express + Socket.IO (จุดเริ่มโปรแกรม)
├── package.json      รายการไลบรารีที่ต้องใช้
├── render.yaml        ค่าตั้งต้นสำหรับ deploy ขึ้น Render
└── public/            ไฟล์หน้าเว็บเกม (เดิมทั้งหมด แก้ให้เชื่อมเซิร์ฟเวอร์)
    ├── index.html          หน้าเข้าสู่การผจญภัย (สร้าง/เข้าร่วมห้อง)
    ├── waiting-room.html   ห้องพักรอนักสำรวจ (ล็อบบี้แบบเรียลไทม์)
    ├── board.html          กระดานเกมหลัก
    ├── spectator.html      จอถ่ายทอดสดสำหรับโปรเจกเตอร์
    ├── board-map.jpg       ภาพพื้นหลังกระดาน
    ├── mod.png             โลโก้เกม/ไอคอนเว็บไซต์ (favicon)
    └── comedu.png          โลโก้สาขาวิชาคอมพิวเตอร์ศึกษา
```

## วิธีรันบนเครื่องตัวเอง (ทดสอบก่อน deploy)

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm start
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
ถ้าจะทดสอบหลายกลุ่มพร้อมกัน ให้เปิดแท็บ/เบราว์เซอร์คนละอันแล้วเข้า URL
เดียวกัน (หรือใช้คอมพิวเตอร์เครื่องอื่นในวง LAN เดียวกันแล้วเข้าด้วย
`http://<ip-เครื่องเซิร์ฟเวอร์>:3000`)

## วิธี Deploy ขึ้น Render ผ่าน GitHub

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในนี้ขึ้นไป (หรือ
   `git init` แล้ว push จากโฟลเดอร์นี้)
2. เข้า [Render Dashboard](https://dashboard.render.com) → **New** →
   **Web Service**
3. เลือก **Build and deploy from a Git repository** แล้วเชื่อมต่อ repo ที่เพิ่ง
   สร้าง (Render จะอ่านค่าจาก `render.yaml` ให้อัตโนมัติ ถ้าไม่ขึ้นให้ตั้งเอง
   ตามนี้)
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** Node
4. กด **Create Web Service** รอ build เสร็จ (ปกติ 1-2 นาที)
5. Render จะให้ URL เช่น `https://mod-nak-samruat.onrender.com` — นำ URL นี้ไป
   แชร์ให้นักเรียนเข้าเล่นได้เลย (ไม่ต้องต่อท้ายชื่อไฟล์ เข้าแค่ URL หลักพอ)

> หมายเหตุ: แพ็กเกจ Render แบบฟรีจะ "หลับ" เมื่อไม่มีคนใช้งานสักพัก และใช้
> เวลาสองสามสิบวินาทีในการตื่นตอนมีคนเข้าใหม่ครั้งแรก — เป็นเรื่องปกติของแพ็กเกจฟรี

## วิธีเล่น (ภาพรวมการไหลของระบบ)

1. ครู/หัวหน้ากลุ่มเปิดหน้าเว็บ กด "สร้างห้อง" ระบบจะสุ่มรหัส PIN ให้
2. แต่ละกลุ่มเปิดหน้าเว็บเดียวกันจากอุปกรณ์ของตัวเอง เลือก "เข้าร่วมห้อง"
   แล้วกรอกรหัส PIN เดียวกัน
3. ทุกคนจะเห็นรายชื่อกลุ่มที่เข้าห้องแบบเรียลไทม์ในหน้าห้องพักรอ
4. เมื่อครบอย่างน้อย 2 กลุ่ม **เฉพาะหัวหน้าห้อง (คนสร้างห้อง)** เท่านั้นที่กด
   "เริ่มออกสำรวจ" ได้ — ทุกอุปกรณ์จะถูกพาไปหน้ากระดานเกมพร้อมกันอัตโนมัติ
5. ในหน้ากระดาน ปุ่มต่าง ๆ (ทอยลูกเต๋า, เลือกการ์ด, ตอบคำถาม) จะกดได้เฉพาะ
   อุปกรณ์ของทีมที่ถึงตาเดินเท่านั้น ทีมอื่นจะเห็นสถานะ "รอตาทีม..." และเห็น
   หมากเดิน/คะแนน/คำถามอัปเดตแบบเรียลไทม์ไปพร้อมกัน
6. เปิด `spectator.html` (ปุ่ม "เปิดจอถ่ายทอดสด" ในห้องพักรอ) บนคอมพิวเตอร์ที่
   ต่อโปรเจกเตอร์ เพื่อฉายภาพกระดานรวมให้ทั้งห้องเรียนดู

## ข้อจำกัดที่ควรทราบ

- สถานะห้อง/เกมเก็บไว้ใน memory ของเซิร์ฟเวอร์เท่านั้น หากเซิร์ฟเวอร์
  รีสตาร์ท (เช่น Render sleep แล้วตื่นใหม่) ห้องที่ค้างอยู่จะหายไป
  ต้องสร้างห้องใหม่
- ปุ่ม "ออกจากเกม" ในหน้ากระดานจะเอาทีมที่ **ถึงตาเดินอยู่ในขณะนั้น** ออกจาก
  เกม (ตามพฤติกรรมเดิมของโค้ดต้นฉบับ) ไม่ใช่เอาผู้กดออก จึงควรให้ทีมที่ถึงตา
  เดินเป็นผู้กดปุ่มนี้เท่านั้น
- ออกแบบไว้สำหรับการเล่นในคาบเรียน/ห้องเดียว (ไม่รองรับหลายห้องพร้อมกันจำนวน
  มากในระดับโปรดักชัน แต่รองรับหลายห้องพร้อมกันได้สบายในระดับใช้งานจริงของ
  โรงเรียน)
